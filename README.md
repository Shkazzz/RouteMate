# RouteMate MVP

## Дорожная карта развития

План версий **0.3–1.0**, приоритеты, сроки, архитектура и критерии приёмки: **[docs/ROADMAP.md](docs/ROADMAP.md)**.

> Дорожная карта описывает планируемую функциональность, а не уже реализованные возможности.

Flutter-приложение для автомобильных поездок: маршрут А→Б, персональные интересы, дети, поиск интересных мест вдоль дороги, выбор остановок, пересчёт времени и экспорт в OpenStreetMap.\n\n## Бесплатный ИИ и резервный поиск POI\n\nВ разделе **Профиль → ИИ-рекомендации** можно указать личный API-ключ Gemini из Google AI Studio. Используется модель `gemini-2.5-flash-lite` с бесплатным тарифом при наличии доступной квоты. Приложение отправляет только состав группы, интересы, названия и категории уже найденных POI, после чего ИИ выставляет рейтинг и кратко объясняет выбор. Ключ не сохраняется на устройстве и никогда не помещается в репозиторий. **Важно:** прямой вызов с мобильного клиента является компромиссом для личного MVP; в публичном релизе использовать серверный прокси, иначе ключ может быть извлечён из трафика/устройства.\n\nЕсли ключ не задан или ИИ недоступен, система сортирует реальные POI обычным алгоритмом. Если Overpass возвращает HTTP 502/тайм-аут, приложение пытается получить реальные географические достопримечательности из Wikipedia Geosearch. Wikipedia отдаёт меньше категорий и не заменяет полноценный каталог POI.\n

## Сборка APK в GitHub

Откройте **Actions → Build RouteMate Android APK → Run workflow**. После успешного выполнения скачайте артефакт **RouteMate-debug-APK**. Это тестовая APK-сборка (не подписанная для публикации в магазине).

## Запуск локально

Установите Flutter SDK и Android SDK. В корне репозитория:

```bash
flutter create . --project-name routemate --org app.routemate --platforms android,ios
flutter pub get
flutter test
flutter run
```

Шаблонные каталоги платформ (Android/iOS) **генерируются Flutter**, а не хранятся как неполные ручные заглушки. Существуют каталоги `lib/`, `lib/models/`, `lib/services/`, `test/`, `.github/workflows/`. Скрипт CI автоматически добавляет разрешение Android `INTERNET` для release/debug APK.

## Бесплатные сервисы и ограничения

- OpenStreetMap + `flutter_map`: карта, attribution.
- Nominatim: геокодирование; соблюдаем ограничение частоты запросов.
- OSRM routing.openstreetmap.de: построение маршрута.
- Overpass: поиск POI небольшими партиями с запасными endpoints.\n- Wikipedia Geosearch: независимый резервный источник географических статей с координатами.\n- Gemini API: необязательная ИИ-персонализация через личный ключ и бесплатный тариф.

Эти публичные ресурсы работают без платных API-ключей, но имеют ограничения доступности и нагрузки. Не использовать как гарантию продакшен-сервиса. Часы работы и автомобильное время отклонения в MVP не подтверждаются; расстояние от точки до маршрута приблизительное. Для коммерческой версии рекомендуется собственный сервер с PostGIS/OSM extract.

При временном отказе Overpass приложение оставляет основной маршрут, показывает понятную ошибку и разрешает повторить поиск.

## Состав

- `lib/main.dart` — интерфейс.
- `lib/models/models.dart` — профиль и рейтинг.
- `lib/services/osm_services.dart` — геокодирование, маршруты и поиск POI.\n- `lib/services/ai_recommendations.dart` — ИИ-ранжирование проверенных POI.
- `test/models_test.dart` — базовые тесты.
- `.github/workflows/android-apk.yml` — сборка APK.

Статус: исходный MVP, GitHub Actions сборка ещё должна пройти успешно, после чего проверить приложение на телефоне.

## Flutter Web: ошибка Failed to fetch / CORS

С версии этого исправления Flutter Web запрашивает POI через Wikipedia Geosearch с обязательным параметром `origin=*` и без пользовательских HTTP-заголовков. Публичные Overpass POST-запросы выполняются только на Android/iOS, поскольку на Web могут блокироваться CORS. Поиск в Web может возвращать меньше POI, чем на Android. Для полного поиска Overpass в браузере необходим собственный серверный API-прокси; бесплатный тариф Gemini сам по себе не исправляет ошибки доступа к источникам POI.

В GitHub Actions теперь собираются APK и отдельный артефакт `RouteMate-Web`. После изменения исходников нужно **заново развернуть** Web-сборку и очистить кэш старой версии в браузере; один коммит в GitHub не обновляет уже опубликованное приложение автоматически.
